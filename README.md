# Lokabuy

![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)

A fully functional classified ads web portal. Built as a **Laravel 8 + Blade monolith** with a versioned REST API, user authentication, listing management, admin moderation, email notifications, and Redis caching.

---

# Architecture Overview

```
Browser / API Client
│
├── routes/web.php ──► Web Controllers ──► Blade Views
│
└── routes/api.php ──► API Controllers ──► API Resources (JSON)
          │
          │  (both stacks share everything below)
          │
     Middleware
     throttle · CORS · auth · role check
          │
     Form Requests
     validate · request-level authorize
          │
     Controllers  (thin — receive, delegate, respond)
          │
     Services     (all business logic)
          │
     ┌────┴────┐
     │         │
  Eloquent   Redis
  Models     cache · queue
     │
  MySQL 8
```

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Backend | Laravel 8, PHP 8.1 |
| Frontend | Laravel Blade, Bootstrap 5, Alpine.js |
| Database | MySQL 8 |
| Cache / Queue | Redis (`predis/predis`) |
| Auth | Laravel Sanctum (Bearer tokens for API, sessions for web) |
| File storage | Local public disk — switchable to S3 via `FILESYSTEM_DRIVER` |
| Code style | Laravel Pint |
| Testing | PHPUnit via `php artisan test` |

## Local Setup

```bash
# 1. Clone the repository
git clone <repo-url>
cd lokabuy

# 2. Install PHP dependencies
composer install

# 3. Copy the environment file
cp .env.example .env

# 4. Generate the application key
php artisan key:generate

# 5. Update .env with your DB credentials, then run migrations and seeders
php artisan migrate --seed

# 6. Link the public storage disk
php artisan storage:link

# 7. Start the development server
php artisan serve
```

Visit: `http://127.0.0.1:8000`

> **Virtual host**: If you use a custom domain (e.g. `lokabuy.test`), set `APP_URL` accordingly and add the domain to `SANCTUM_STATEFUL_DOMAINS` in `.env`.

## Environment Variables

Copy `.env.example` to `.env` and update the values below. Variables not listed here can be left at their defaults.

| Variable | Required | Description |
|----------|----------|-------------|
| `APP_URL` | Yes | Full URL of the local app (e.g. `http://lokabuy.test`) |
| `APP_KEY` | Yes | Auto-generated by `php artisan key:generate` |
| `APP_DEBUG` | — | Set to `false` in production |
| `DB_HOST` | Yes | MySQL host (default `127.0.0.1`) |
| `DB_PORT` | — | MySQL port (default `3306`) |
| `DB_DATABASE` | Yes | Database name (e.g. `lokabuy`) |
| `DB_USERNAME` | Yes | MySQL username |
| `DB_PASSWORD` | — | MySQL password (leave empty if none) |
| `REDIS_HOST` | Yes | Redis host (default `127.0.0.1`) |
| `REDIS_PORT` | — | Redis port (default `6379`) |
| `REDIS_PASSWORD` | — | Redis password (`null` if none) |
| `MAIL_HOST` | Yes | SMTP host (use Mailtrap for local testing) |
| `MAIL_PORT` | — | SMTP port (default `587`) |
| `MAIL_USERNAME` | Yes | SMTP username |
| `MAIL_PASSWORD` | Yes | SMTP password |
| `MAIL_FROM_ADDRESS` | — | Sender address (default `noreply@lokabuy.com`) |
| `FILESYSTEM_DRIVER` | — | `public` (local) or `s3` for production |
| `SANCTUM_STATEFUL_DOMAINS` | Yes | Comma-separated frontend domains for Sanctum cookies |
| `CORS_ALLOWED_ORIGINS` | Yes | Comma-separated origins allowed to call the API |
| `ADMIN_EMAIL` | Yes | Email address for the seeded admin account |
| `ADMIN_PASSWORD` | Yes | Password for the seeded admin account |

## API Quick Reference

All endpoints are under `/api/v1`. Every response uses the standard envelope:

```json
{ "success": true, "data": {}, "error": null }
```

Authenticated endpoints require a Bearer token:
```
Authorization: Bearer <token>
```

### Authentication

**Register**
```bash
curl -s -X POST http://localhost:8000/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"name":"John Doe","email":"john@example.com","password":"Secret@1234","password_confirmation":"Secret@1234"}' \
  | jq .
```

**Login**
```bash
curl -s -X POST http://localhost:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"john@example.com","password":"Secret@1234"}' \
  | jq .
# Save the token: TOKEN=$(... | jq -r '.data.token')
```

**Logout**
```bash
curl -s -X POST http://localhost:8000/api/v1/auth/logout \
  -H "Authorization: Bearer $TOKEN" | jq .
```

### Listings

**Browse / search listings**
```bash
curl -s "http://localhost:8000/api/v1/listings?q=iphone&category=electronics&city=Mumbai&price_max=50000&sort=price_asc" \
  | jq .
```

**Get a single listing**
```bash
curl -s http://localhost:8000/api/v1/listings/iphone-14-pro-abc123 | jq .
```

**Create a listing** *(requires auth + verified email)*
```bash
curl -s -X POST http://localhost:8000/api/v1/listings \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "iPhone 14 Pro 256GB",
    "description": "Excellent condition, bought 6 months ago.",
    "price": 75000,
    "category_id": 3,
    "location_city": "Mumbai",
    "location_state": "Maharashtra",
    "location_country": "India"
  }' | jq .
```

**Toggle favorite**
```bash
curl -s -X POST http://localhost:8000/api/v1/favorites/iphone-14-pro-abc123 \
  -H "Authorization: Bearer $TOKEN" | jq .
```

**My listings**
```bash
curl -s http://localhost:8000/api/v1/my/listings \
  -H "Authorization: Bearer $TOKEN" | jq .
```

Full endpoint documentation: [`docs/openapi.yaml`](docs/openapi.yaml)

## Running Tests

```bash
# Run all tests
php artisan test
```

For isolated test runs, create a `.env.testing` file with a separate test database:

```dotenv
APP_ENV=testing
DB_DATABASE=lokabuy
CACHE_DRIVER=array
QUEUE_CONNECTION=sync
MAIL_MAILER=array
```

Then run:
```bash
php artisan migrate --env=testing
php artisan test
```

## Code Style

The project uses **Laravel Pint** (PSR-12 + Laravel preset). Run before every commit:

```bash
./vendor/bin/pint
```

To check without making changes:
```bash
./vendor/bin/pint --test
```

All PHP files must begin with `declare(strict_types=1)`.
